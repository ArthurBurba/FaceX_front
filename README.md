# FaceX_front

Frontend do projeto **X-FACE** desenvolvido com Python (PySide6) e QML.

---

## Rodar a Interface

### 1. Instalar as dependências do Frontend
```bash
pip install PySide6 sqlalchemy
```

### 2. Rodar a interface de teste

```bash
python3 -m central.interface
```
